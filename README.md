# Expense Tracker 💰

Expense Tracker is a Python-based project designed to help users manage and track their daily expenses.

## Features
- Add and record expenses
- Manage expense records
- Store expense data in CSV format
- Simple and easy-to-use Python program

## Technologies Used
- Python 🐍
- CSV

## Project Files
- `main.py` – Main program
- `expense_manager.py` – Expense management functions
- `expenses.csv` – Stores expense records

## How to Run

Run the following command:

```bash
python main.py

Purpose

This project was created to practice Python programming and learn how to manage data using files and modules.
